Identity specification

No value is chosen where one can be derived. The identity does not illustrate the reasoning — it executes it.

01 · Typeface

Switzer, weight 700

The identity is set in Switzer Bold (Indian Type Foundry, via Fontshare; ITF Free Font License, commercial use permitted — the license ships with the fonts in this repository). Weights 400–700 are self-hosted as woff2. The typeface is an input to the identity, not part of its definition: change the font, re-run the derivation, and every number below re-emits.

02 · The stacked master

REASONED over WEB, justified by derivation

Both lines are set at the same size and the same measure. Line 1 carries a fixed 0.02em tracking. The tracking of WEB is not chosen — it is the number that makes the second line as wide as the first:

W₁5462ushaped width of REASONED (real kerning) + 7 × 20u tracking
W₂2296ushaped width of WEB (real kerning)
gap(W₁ − W₂) / 2 = 1583u = 1.583emapplied in each of the two W·E·B channels
vertical channel= m = capHeight / 3 = 235.7u = 0.2357emthe glyph's own rule: its channel is m in a mark 3m tall. (An earlier derivation, channel = gap, was rejected — too much air.)

CSS semantics: letter-spacing leaves space after the last letter; it is trimmed with an equal negative margin-right. Line 1: letter-spacing: 0.02em; margin-right: -0.02em. Line 2: letter-spacing: 1.583em; margin-right: -1.583em.

03 · The glyph

The master at minimum resolution

Module m; measure 5m. A solid bar of 5m × m — REASONED, massive — over three m × m squares — W·E·B, counted — separated by gaps of m; vertical gap m. Four fills, zero strokes: it cannot break at 16 px. The shape is the name: it cannot be copied without copying the name.

viewBox 100m = 12 · bar x20 y32 60×12 · squares 12×12 at y56, x 20 / 44 / 68
favicon gridmpx = round(size × 12/100): 16px→2 · 32px→4 · 48px→6 — whole-pixel grid, no antialiasing
04 · The lockup

Glyph beside the name

For navigation, signatures, and co-branding contexts. The glyph is scaled so its full height (3m) equals the text's cap height — m = capHeight / 3 = 235.7u — and sits on the same baseline. The space between glyph and text is one module, m: the grid continues. The text is “Reasoned Web” in title case, Switzer 700, tracked −0.015em — the one optical value in this identity, declared as such and refined by eye.
